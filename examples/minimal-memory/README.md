# Minimal Memento Demo

This tiny example shows how Memento Skill turns a messy research note into a
controlled memory layout.

## Input

See [messy-notes.md](./messy-notes.md).

## Output

- [CURRENT_STATE.md](./CURRENT_STATE.md): short hot path for the next agent
- [ACTIVE_TRACKER.csv](./ACTIVE_TRACKER.csv): decision-relevant evidence only
- [runs.csv](./runs.csv): factual ledger
- [contrasts.csv](./contrasts.csv): predictions, controls, outcomes
- [hypotheses.md](./hypotheses.md): belief state and update rules
